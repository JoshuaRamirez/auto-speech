# Plan

The specification told us *what* to build and *why*. The plan tells us *how* and
*in what order*, and how each phase will invoke the **OOAD micro process**
(identify classes → identify semantics → identify relationships → specify
interface and implementation) at the appropriate level of abstraction.

## Files
- [implementation-plan.md](implementation-plan.md) — phased plan with micro-process stubs per phase.
- [phase-breakdown.md](phase-breakdown.md) — each phase's concrete tasks.
- [artifact-map.md](artifact-map.md) — inventory of every artifact produced.
- [risk-register.md](risk-register.md) — known risks + mitigations.

# Speech Synthesis Output Guidelines

When auto-speech is active, responses are synthesized into audio speech via the Apple Say neural voice.
To ensure spoken responses sound natural, concise, and pleasant to listen to:

- **Conversational Summaries**: Keep concluding answers and spoken turn responses direct and conversational.
- **Avoid Markdown Litter in Speech**: Do not read out large markdown code fences, ASCII art, raw URLs, or complex file paths verbatim. Summarize what changed or where the file is.
- **Highlight Key Takeaways**: Prioritize the decisive insight or outcome first.
